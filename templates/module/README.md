# __MODULE__

A Terraform module generated by [`stricttf`](https://github.com/ilvar/stricttf).

It starts in the strict subset and is set up to stay there: the same gate
runs in `scripts/check.sh`, in `make check`, in the pre-commit hooks, and in
CI, so a module that passes locally passes everywhere.

## Usage

```hcl
module "example" {
  source = "../__MODULE__"

  name = "example"
  tags = {
    team = "platform"
  }
}
```

| Input | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | required | 2-64 lowercase letters, digits, and hyphens |
| `tags` | `map(string)` | `{}` | merged over the module's default tags |

| Output | Description |
| --- | --- |
| `name` | name of the object this module manages |
| `tags` | effective tags after merging |

## Requirements

| Tool | Purpose | Required |
| --- | --- | --- |
| [`terraform`](https://developer.hashicorp.com/terraform) 1.6+ (CI pins the version in `.terraform-version`) | fmt, init, validate, test | yes |
| [`stricttf`](https://github.com/ilvar/stricttf) | strict-subset gate | yes |
| [`tflint`](https://github.com/terraform-linters/tflint) | extra lint rules | optional |

## The gate

```bash
scripts/check.sh   # the whole gate, cheapest check first
make check         # the same stages as make targets
stricttf check .   # one JSON document, deterministically ordered
```

`scripts/check.sh` runs `stricttf check`, `terraform fmt -check`,
`terraform init -backend=false`, `terraform validate`, `terraform test`,
and `tflint`, and reports loudly which optional stages it skipped, so a
green run never means nothing was checked.

The module needs no provider: it is built on the builtin `terraform_data`
resource, so the whole gate runs offline. Replace it with real resources
as the module grows.

## Layout

```text
versions.tf             Terraform version constraint
variables.tf            typed, described, validated inputs
main.tf                 the module itself
outputs.tf              described outputs
tests/                  terraform test suites (plan only)
.github/workflows/      the same gate, in CI
```
